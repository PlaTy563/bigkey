# BigKey

QWERTYのローマ字入力で日本語を打てる、キーを大きくしたAndroid用キーボード。

## 使い方

1. GitHubにpushする（`main`ブランチ）と、GitHub ActionsがAPKをビルドする。
2. Actionsの実行結果の `apk` からAPKを取得してインストールする（保持期間は3日）。
3. アプリ「BigKey」を開き、「入力方法の設定」で有効化、「切り替え」で選択する。

## 署名

- デバッグ署名: `keystore/debug.keystore`（標準パスワード、非秘匿）を固定で使う。ビルドごとに署名が変わらないため、上書きインストールできる。
- リリース署名: GitHub Secretsに以下を設定すると使われる。未設定ならデバッグ署名になる。
  - `KEYSTORE_BASE64`（keystoreファイルをbase64化したもの）
  - `KEYSTORE_PASSWORD`
  - `KEY_ALIAS`
  - `KEY_PASSWORD`
- 本物のリリースkeystoreはコミットしない（`.gitignore`で除外済み）。

## 配布

`v*` のタグをpushすると、APKがGitHub Releaseに添付される。Releaseはartifactの保存枠を消費しない。

```
git tag v0.1.0
git push origin v0.1.0
```

## 辞書・変換

- 変換辞書は Mozc (OSS版) の辞書と接続表から作った `app/src/main/assets/dict.bin` と `conn.bin`。ライセンスは `licenses.txt`（アプリの設定画面からも見られる）。
- 作り直す手順: `python3 -I tools/build_dict.py <Mozcのdictionary_ossのフォルダ> <出力先> --max-cost 6300 --kata-max-cost 5300 --per-reading 20（dict.bin / conn.bin / pos.bin ができる。3つともassetsに置く）`
- 変換は文全体の最適な区切りを探す方式（`Converter.java`）。手元での確認は `tools/ConverterCli.java`。
- 自動変換: 打ちながら変換結果を表示する。確信のある単語だけ変換し、他の候補と僅差の単語（かんじ→感じ/漢字 など）と、末尾の打ちかけの2文字はひらがなのまま残す。スペースで全体を変換する。設定でオフにできる。
- 選んだ候補は単語ごとに学習し、バックアップに含まれる。

## Bitwarden

- 候補バーの右端に Bitwarden を開くボタンを出す。
- Android 11 以上で、Bitwarden を自動入力サービスに選び、インライン候補を有効にすると、ログイン候補がキーボード上に出る。

## バックアップ

アプリ画面から、設定と学習履歴をJSONファイルに書き出し・復元できる。

## 入力モードと記号

- 左下のキーが「日本語」（青）／「English」（橙）で現在のモードを示す。スペースキーにもモード名を出す。
- 文字キーの右上に小さく出ている数字・記号は、そのキーを長押しすると入力できる（記号の画面に切り替えなくてよい）。

## 見た目

- 端末の暗い表示／明るい表示に合わせて配色が切り替わる（`Theme.kt`）。
- キーは平らな角丸で、削除・Shift・Enter は線で描いた図形。Enter は淡い青、モード表示は青（日本語）／橙（English）。
- 候補バーは背景と同じ色で、選択中の候補だけ丸い色付きの枠で示す。

## 編集とクリップボード

- 上の段のクリップボードのアイコンを1回押すと、コピーした文の履歴と定型文が開く。全選択、コピー、切り取り、貼り付けのボタンもここにある。
- 履歴の文をタップするとその位置に入力される。「固定」を押した文は保存され、バックアップにも含まれる。固定していない履歴はキーボードの終了とともに消える。
- パスワード管理アプリなどが機密として印を付けたコピーは、履歴に残さない。
- スペースキーの上を左右になぞると、カーソルが動く。

## 予測変換と候補の整理

- 1文字から、その読みで始まる単語を予測として候補に出す（最有力の変換結果の次に並ぶ）。予測に使うのは名詞・副詞・動詞と形容詞の基本形などに限る（`pos.bin`）。
- 人名は低頻度のものを辞書から除き、助詞などの短い語を別の漢字やカタカナに替える候補は出さない。
- 候補バーの候補を長押しすると、その候補を今後出さない。外した候補は設定からすべて戻せる。バックアップにも含まれる。

## 定型文・絵文字・音声入力

- 定型文: 設定画面の「定型文」で追加・削除する。上の段のクリップボードのアイコンを開くと、一番上に並び、タップで入力できる。編集パネルの履歴から「定型文に登録」もできる。バックアップに含まれる。
- 絵文字: 候補バーの「絵文字」で、カテゴリごとの一覧を開く。タップで入力する。
- 音声入力: 候補バーの「音声」で、端末の音声認識の画面を開く。話し終えると入力欄に文字が入る。端末の音声認識（Google など）が必要。

## 学習・ユーザー辞書（0.10.0）
- 日本語モードの長押し記号に全角の「」・（）『』〜！？を追加。
- 直前の語との組み合わせを覚え、同音語の選び方に反映する。
- タップ位置のずれを少しずつ学習する（設定でオフ・リセット可）。
- キーを押している間、上に拡大表示を出す。
- ユーザー辞書: 設定画面で追加・削除。タブまたはカンマ区切りのテキスト（Google日本語入力・Mozc・MS-IMEなど）を読み込み、書き出しもできる。文字コードは自動判定。バックアップにも含まれる。
- 確定後、次に続きそうな言葉を候補バーに表示する。
- 絵文字は読みで検索でき、パネルに「最近」を追加。

## 使いやすさの改善（0.11.0）
- 英字入力中に、英単語の候補を表示（よく使われる25000語。パスワード・メール・URL欄では出さない）。
- 削除キーを左へなぞると、1語ずつ消える。
- ツールバーの「範囲選択」を押すと、カーソルの矢印（とスペースのなぞり）で範囲を選べる。
- 確定した直後に「↩ 戻す」を表示。押すと読みに戻り、次の候補を表示する。
- 候補バー右端の矢印で、候補を一覧で表示。
- ツールバーのボタンを、設定で並び替え・非表示にできる。

## 画面の構成

- 一番上の段に、カーソル移動（左右の矢印、押し続けると繰り返す）・クリップボード・絵文字（顔）・音声（マイク）のアイコン（左）と Bitwarden（鍵のアイコン、右）、その下の段に変換候補を出す。候補の幅を広く使える。
